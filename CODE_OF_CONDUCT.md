# Community Code of Conduct

LX Capture is intended to be a respectful and constructive project space.

## Expected behavior

- Be considerate and direct in technical discussions.
- Review code and ideas without attacking people.
- Respect privacy, consent, and personal boundaries.
- Accept corrections and different levels of experience in the community.

## Unacceptable behavior

Harassment, discrimination, threats, personal attacks, unwelcome sexual attention, and sharing another person's private information are not acceptable in project spaces.

## Reporting

Report conduct concerns privately through the repository owner's GitHub profile. Do not post private screen recordings, credentials, or personal data in a public issue. Project maintainers will review reports and take proportionate action.
